## Overview

This repository documents my competitive programming journey. Every solution is either solved independently or re-implemented from scratch after studying the editorial.
The focus is on understanding the underlying idea, not just getting an accepted verdict.

## Revision Workflow

1. Attempt each problem independently before looking at hints
2. If stuck, read the editorial and note the key idea in the solution header
3. Re-implement the solution from scratch without referring to the old code
4. Revisit difficult problems after a week to confirm the idea has stuck
